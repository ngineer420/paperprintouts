Blank periodic table

Every blank periodic table online is a fixed image. This one lets you choose what is missing, and prints the answer key from the same settings.

Settings

Pick which parts of each cell are shown and which are left blank for the student to fill in. Colour by category, by block, or by metal and non-metal, or turn colour off entirely to save toner.

All 118 elements are included, with the lanthanides and actinides on their usual rails below the main table.

Questions

Is the data accurate?

Atomic numbers, symbols, names and standard atomic weights are from the IUPAC published values. Weights are shown to four significant figures.

Can I print it in black and white?

Yes — set colouring to none. The category outline stays, so the shape of the table is still readable.

Does it fit on one page?

On Letter or A4 in landscape, yes. Portrait works but the cells are small; tabloid or A3 gives the most room for writing.
